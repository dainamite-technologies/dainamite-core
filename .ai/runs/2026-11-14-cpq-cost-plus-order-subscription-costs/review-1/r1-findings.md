## Summary

Counts: blocker 0, major 3, minor 2, nit 1.

Major: #1 ARC activation never links `order_line_cost.inventory_cost_id`; #2 reconfigured-mirror `replace` ends item costs the quote could never carry (toggle off -> all costs; manual costs always); #3 order margin includes ARC mirror lines that the quote margin excludes.

Checked and found clean:
- Activation transaction: every read/write inside `activateOrder` goes through `tx` (helpers take `em`, inventory via `withEntityManager(tx)`, no `this.em` access inside; `isInTransaction` guard; DTO built on a throwaway read fork); lifecycle and `cost_changed` events emitted only after `transactional` resolves; `{ clear: true }` is a valid MikroORM 7 TransactionOptions key.
- Conversion copy inside the `withQuotePricingWrite` transaction, before the flush; deleted lines skipped; `total_amount` = instance x quantity (same as quote margin); quote cost currency is already the quote currency, so UI money labels are right.
- inventoryCostSync: one row per (owner, cost_key) incl. ended rows (Q9 reactivation updates in place, never inserts), no-op detection with numeric/jsonb-aware comparison, owner xor check, duplicate-key guard; write order cannot violate the partial unique indexes (same key -> same row; merge re-point targets fresh clone ids; asset re-point keeps `asset_id`). Q12 ordering (costs -> flush -> after-snapshot -> pre-generated change-log id -> last_change_id -> flush) in createSubscription, applyAmendment, applyRenewal, applyMergeRenewal, applyCancel. Q8 `ended_at` = change-log effective date. Q2 asset vs item ownership correct (new-sale assets own costs, ARC add assets do not).
- `_arcReconfigured` / `_arcCostPlusFrozen`: client-sent `_arc*` keys are stripped (`stripArcMarkers`) before the server sets markers; both are in `QUOTE_ONLY_ARC_KEYS` and stripped from order lines / items / assets; activation reads them from the source quote line. Frozen Renew cost-plus lines have no cost lines so cannot block conversion; reconfigured mirrors allow cost confirmation ('value' mode).
- Confidentiality: three new GET routes use `requireFeatures`, `openApi`, Zod params, toggle 404 first, wildcard-aware `rbacService.userHasAllFeatures` for `cpq.costs.view`; status-only projections carry no amount/supplier/fx/margin; change-log route strips `items[].costs`/`assets[].costs` when no feature or toggle off; `cost_changed` is `clientBroadcast: false` with ids only; lifecycle payload builders read only id/name from snapshots; stored charges carry no cost data.
- Tenant scoping + `deletedAt: null` on every new query; snapshot costs in one query; reads bounded per order/subscription; usage count uses semi-joins.
- UI: `apiCall` everywhere (raw `fetch` on the change log migrated), `Button`, `t(key, fallback)`, injection spot `data-table:cpq.inventory_asset_costs`, 404 hides sections.
- Scrub CLI: keyset paging, `nativeUpdate`, idempotent, dry-run writes nothing.
